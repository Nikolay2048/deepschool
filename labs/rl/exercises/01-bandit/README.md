# Задание 01. Multi-armed bandit

Цель: написать самый первый RL-эксперимент без нейросетей и сложных сред.

## Что нужно сделать

Допиши Python-скрипт `bandit.py`, который моделирует `k` игровых автоматов.

Минимальная версия:

1. Допиши `BanditEnv.step`.
2. Допиши `EpsilonGreedyAgent.choose_action`.
3. Допиши `EpsilonGreedyAgent.update`.
4. Допиши цикл в `run_experiment`.
5. Запусти обучение на 1000 шагов.
6. Проверь вывод:
   - истинные средние награды автоматов;
   - оцененные агентом средние награды;
   - сколько раз агент выбрал каждый автомат;
   - суммарную награду.

## Где писать код

Пиши здесь:

```text
labs/rl/exercises/01-bandit/bandit.py
```

## Важная формула

Оценку средней награды действия можно обновлять инкрементально:

```text
Q_new = Q_old + (reward - Q_old) / N
```

где:

- `Q_old` - старая оценка средней награды;
- `reward` - новая полученная награда;
- `N` - сколько раз это действие уже было выбрано.

## Как я буду проверять

Когда напишешь код, я посмотрю:

- правильно ли разделены среда и агент;
- есть ли exploration;
- корректно ли обновляются оценки `Q`;
- воспроизводится ли результат через seed;
- понятно ли выводятся результаты.
