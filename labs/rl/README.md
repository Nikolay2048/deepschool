# Reinforcement Learning

Здесь будет учебный трек по reinforcement learning.

Формат работы:

1. Я сохраняю подробную лекцию в `lectures/`.
2. В `exercises/` появляется маленькое практическое задание.
3. Ты пишешь код сам.
4. Я делаю ревью, объясняю ошибки и помогаю улучшить решение.

## План

1. Что такое RL: агент, среда, действия, награды, эпизоды.
2. Multi-armed bandits: epsilon-greedy, exploration vs exploitation.
3. Markov decision process: состояния, переходы, value function.
4. Dynamic programming: policy evaluation, value iteration.
5. Monte Carlo methods.
6. Temporal-difference learning: TD(0), SARSA, Q-learning.
7. Function approximation: когда таблиц уже не хватает.
8. Deep Q-Networks.
9. Policy gradients.
10. Actor-critic.
11. PPO на высоком уровне.
12. Практические ловушки RL: нестабильность, reward hacking, eval.

## Файлы

- `lectures/` - лекции.
- `exercises/` - задания и твои решения.
- `glossary.md` - общий словарь терминов.
- `lecture-log.md` - журнал лекций и текущего прогресса.
- `notes/` - твои личные заметки по ходу обучения.
