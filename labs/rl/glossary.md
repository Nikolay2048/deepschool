# RL Glossary

Живой словарь терминов по reinforcement learning. Новые термины добавляем в конец таблицы по мере появления в лекциях и коде.

| Term | Meaning | Notes |
|------|---------|-------|
| `agent` | Система, которая принимает решения и действует в среде. | Игрок, робот, торговый бот, LLM-агент, рекомендательная система. |
| `environment` | Среда, в которой действует агент. | Принимает действие агента и возвращает новое состояние, награду и признак завершения. |
| `state` | Состояние мира или задачи, на основе которого агент принимает решение. | Например позиция персонажа, доска, признаки пользователя, история диалога. |
| `observation` | То, что агент видит. | Может совпадать с полным `state`, а может быть только частью информации. |
| `action` | Действие, которое выбирает агент. | В bandit-задаче action - это индекс автомата. |
| `reward` | Численная награда за действие или его последствия. | Задает направление обучения. Плохая награда может вести к странному поведению. |
| `policy` | Стратегия выбора действий. | `policy(state) -> action` или распределение вероятностей по actions. |
| `episode` | Один законченный проход взаимодействия агента со средой. | Например одна партия, один маршрут, один диалог. |
| `return` | Суммарная будущая награда. | Часто считается с discount: `G = r1 + gamma * r2 + ...`. |
| `gamma` | Коэффициент дисконтирования будущих наград. | Близко к `0` - важнее ближайшая награда; близко к `1` - важнее далекое будущее. |
| `exploration` | Исследование новых действий. | Агент иногда пробует неочевидные варианты, чтобы найти лучшее поведение. |
| `exploitation` | Использование уже известных хороших действий. | Агент выбирает действие, которое сейчас кажется лучшим. |
| `multi-armed bandit` | Простая RL-задача без состояния: несколько действий с неизвестными наградами. | Хороший первый пример для exploration vs exploitation. |
| `epsilon` | Вероятность exploration в epsilon-greedy стратегии. | `epsilon = 0.1` значит примерно 10% случайных действий. |
| `epsilon-greedy` | Стратегия: иногда случайное действие, иначе действие с максимальным `Q`. | Простой baseline для баланса exploration/exploitation. |
| `Q-value` | Оценка полезности действия или пары состояние-действие. | В bandit: `Q[action]` - оценка средней награды автомата. |
| `total reward` | Суммарная награда за все шаги запуска. | `total_reward = r1 + r2 + ... + rN`. |
| `average reward` | Средняя награда за шаг. | `average_reward = total_reward / steps`. |
| `best action rate` | Доля шагов, когда агент выбрал настоящий лучший action. | В bandit можно посчитать, потому что известны `true_values`. |
| `learning curve` | График качества обучения по шагам. | Например cumulative average reward по времени. |
| `run` | Один независимый запуск эксперимента. | Обычно новый seed, новая среда и новый агент. |
| `seed` | Начальное значение генератора случайных чисел. | Нужно, чтобы эксперимент можно было повторить. |
| `mean` | Среднее значение набора чисел. | `mean = sum(values) / len(values)`. |
| `standard deviation` | Мера разброса значений вокруг среднего. | Большое значение означает нестабильные результаты между runs. |
| `cumulative average reward` | Средняя награда с начала запуска до текущего шага. | Используется для learning curves: показывает процесс обучения во времени. |
| `noisy reward` | Награда со случайным шумом вокруг среднего значения. | В bandit хороший автомат не обязан давать хорошую награду на каждом отдельном шаге. |
| `GridWorld` | Учебная среда, где агент ходит по клеткам сетки. | Нужна, чтобы перейти от bandit к задачам со state и transition. |
| `transition` | Переход из одного состояния в другое после действия. | `state + action -> next_state`. |
| `terminal state` | Состояние, где эпизод заканчивается. | В GridWorld это обычно цель. |
| `MDP` | Markov Decision Process, формальная модель последовательного принятия решений. | Содержит states, actions, transitions, rewards и terminal/horizon. |
| `Markov property` | Будущее зависит от текущего состояния и действия, а не от всей истории. | В GridWorld достаточно знать текущую позицию агента. |
| `random policy` | Стратегия, которая выбирает действия случайно. | Полезна как baseline до обучения. |
| `baseline` | Простое решение для сравнения с более сложным алгоритмом. | Если обучение не лучше baseline, нужно искать ошибку или менять постановку. |
| `success rate` | Доля эпизодов, где агент достиг цели. | `success_rate = successful_episodes / total_episodes`. |
| `episode length` | Количество шагов в эпизоде. | Часто ограничивается через `max_steps`, чтобы эпизод не был бесконечным. |
| `Q-table` | Таблица значений `Q(state, action)` для маленькой дискретной среды. | В GridWorld можно хранить как `dict[state][action]`. |
| `Q-learning` | Алгоритм, который учит `Q(state, action)` через reward и лучший будущий Q. | Базовая формула: `Q <- Q + alpha * (target - Q)`. |
| `alpha` | Learning rate в Q-learning. | Управляет тем, насколько сильно новая информация меняет старую Q-оценку. |
| `greedy policy` | Стратегия, которая всегда выбирает действие с максимальным Q. | Используется после обучения, чтобы проверить, чему агент научился. |
| `training` | Режим, где агент собирает опыт и обновляет свои параметры или Q-values. | Во время training обычно включен exploration. |
| `evaluation` | Режим проверки уже обученной политики. | Обычно exploration выключают и используют greedy policy. |
| `learned policy` | Политика, полученная после обучения. | В Q-learning это greedy policy по выученной Q-table. |
| `training curve` | График метрик во время обучения. | Показывает, как reward, success rate или длина эпизода меняются по episodes. |
| `rolling average` | Скользящее среднее по последним значениям. | Сглаживает шумные RL-метрики, например среднее последних 20 episodes. |
| `value function` | Функция ценности состояния. | Показывает, насколько хорошим агент считает состояние. |
| `V(state)` | Ценность состояния. | В Q-learning можно считать как `max_a Q(state, action)`. |
| `heatmap` | Цветовая карта значений. | В GridWorld показывает value каждой клетки после обучения. |
| `exploration decay` | Постепенное уменьшение `epsilon` во время обучения. | В начале агент больше исследует, ближе к концу больше использует learned policy. |
| `epsilon schedule` | Правило, по которому `epsilon` меняется по episodes. | Например constant epsilon или linear decay от `1.0` до `0.05`. |
| `stochastic transition` | Переход, где одно и то же действие может привести к разным результатам. | Например агент выбирает `up`, но среда иногда выполняет случайное действие. |
| `slip probability` | Вероятность, что intended action будет заменен случайным actual action. | В stochastic GridWorld моделирует шумную среду. |
| `intended action` | Действие, которое выбрал агент. | То, что агент хотел сделать. |
| `actual action` | Действие, которое реально выполнила среда. | В stochastic среде может отличаться от intended action. |
