# Лекция 11. Exploration decay

В Q-learning агент выбирает действия через epsilon-greedy:

```text
с вероятностью epsilon выбрать случайное действие
иначе выбрать лучшее действие по Q-table
```

До сих пор `epsilon` был постоянным.

Например:

```python
epsilon = 0.2
```

Это значит, что агент всегда делает случайное действие примерно в 20% случаев, даже когда уже хорошо выучил путь.

## Почему постоянный epsilon не идеален

В начале обучения агент ничего не знает.

Ему нужно много exploration:

```text
пробовать разные действия
натыкаться на стены
находить цель
собирать опыт
```

Но ближе к концу обучения агент уже имеет полезную Q-table.

Если он продолжает делать много случайных действий, это мешает:

- training reward остается шумным;
- episode length может быть больше;
- агент продолжает специально делать плохие ходы ради exploration.

## Идея decay

Exploration decay постепенно уменьшает `epsilon`.

Например:

```text
episode 1:   epsilon = 1.00
episode 100: epsilon = 0.50
episode 300: epsilon = 0.10
episode 500: epsilon = 0.05
```

Интуиция:

```text
сначала много исследуем
потом все больше используем найденную стратегию
```

## Linear decay

Самый простой вариант - линейное уменьшение:

```text
epsilon = start + progress * (end - start)
```

Где:

- `start` - начальный epsilon;
- `end` - минимальный epsilon;
- `progress` - доля пройденного обучения от `0` до `1`.

Если:

```python
start = 1.0
end = 0.05
```

то epsilon плавно идет от `1.0` к `0.05`.

## Почему не опускать epsilon до нуля

Обычно оставляют маленький минимум:

```python
epsilon_end = 0.05
```

Это значит, что агент все еще иногда исследует.

В стабильной маленькой среде можно поставить `0.0`, но во многих задачах полезно оставить небольшой exploration.

## Что сравним

Сравним два режима:

```text
constant epsilon = 0.2
decaying epsilon = 1.0 -> 0.05
```

Будем смотреть:

- reward по episodes;
- success rate;
- steps;
- саму кривую epsilon.

## Главная идея

Постоянный epsilon прост и понятен.

Decay ближе к реальной практике:

```text
в начале учимся через exploration
в конце закрепляем learned policy через exploitation
```
