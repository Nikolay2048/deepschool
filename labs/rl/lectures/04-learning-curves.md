# Лекция 04. Learning curves

До этого мы смотрели на итоговые числа:

- `total_reward`;
- `average_reward`;
- `best_action_rate`;
- `mean`;
- `standard deviation`.

Это полезно, но такие числа показывают только результат после всех шагов.

Иногда важнее увидеть **как агент учился во времени**.

## Что такое learning curve

Learning curve - это график качества по шагам обучения.

В bandit-задаче удобно смотреть:

```text
x: шаг обучения
y: средняя награда с начала запуска до текущего шага
```

Это называется cumulative average reward.

Если награды были:

```text
1, 0, 2, 1
```

то cumulative average:

```text
step 1: 1 / 1 = 1.00
step 2: (1 + 0) / 2 = 0.50
step 3: (1 + 0 + 2) / 3 = 1.00
step 4: (1 + 0 + 2 + 1) / 4 = 1.00
```

## Почему не просто reward на каждом шаге

Reward на каждом отдельном шаге шумный.

Даже хороший автомат иногда дает плохую награду, а плохой иногда может случайно дать хорошую.

Если рисовать raw reward, график будет дергаться.

Cumulative average сглаживает шум и показывает общую тенденцию.

## Что мы ожидаем увидеть

Для разных `epsilon` кривые обычно ведут себя по-разному.

### `epsilon = 1.0`

Агент всегда выбирает случайное действие.

Кривая может стабилизироваться около среднего качества случайной стратегии.

### `epsilon = 0.0`

Агент не исследует случайно.

Иногда быстро находит хорошее действие, иногда застревает. На одном графике это может выглядеть хорошо или плохо в зависимости от seed.

### `epsilon = 0.1`

Часто хороший компромисс.

Кривая может расти медленнее, чем удачный `epsilon = 0.0`, потому что агент тратит часть шагов на exploration. Но в среднем по многим запускам такая стратегия обычно надежнее.

## Один график или много запусков

Есть два режима:

1. Один run на каждый `epsilon`.
2. Средняя кривая по нескольким runs.

Один run проще и нагляднее.

Средняя кривая честнее.

В этом задании начнем с одного run, чтобы увидеть механику. Потом можно будет усреднить.

## Главная идея

Итоговая таблица отвечает на вопрос:

```text
Кто победил в конце?
```

Learning curve отвечает на вопрос:

```text
Как агент к этому пришел?
```

Это важное различие. В RL процесс обучения часто так же важен, как финальный результат.
