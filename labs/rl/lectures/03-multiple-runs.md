# Лекция 03. Почему одного запуска мало

В предыдущем задании мы сравнили разные значения `epsilon` на одном запуске.

Это полезно, но в RL один запуск часто может обмануть.

## Откуда берется случайность

В нашем bandit-примере случайность есть сразу в нескольких местах.

### Случайные настоящие значения автоматов

При создании среды мы делаем:

```python
self.true_values = [self.rng.gauss(0.0, 1.0) for _ in range(k)]
```

Это значит, что в одном запуске лучший автомат может быть очень хорошим, а в другом - только слегка лучше остальных.

### Случайная награда

Даже если у автомата средняя награда `0.7`, конкретная награда может быть ниже или выше:

```python
reward = rng.gauss(true_mean, reward_std)
```

Один плохой случайный reward в начале может испортить оценку действия.

### Случайный exploration

Если `epsilon > 0`, агент иногда выбирает случайные действия.

В одном запуске он может быстро наткнуться на лучший автомат. В другом - долго его не пробовать.

## Почему `epsilon = 0.0` мог победить

В одном из наших запусков `epsilon = 0.0` дал лучший результат.

Это не обязательно значит, что `epsilon = 0.0` лучшая стратегия.

В том конкретном seed агенту повезло:

- первые действия разочаровали его в плохих автоматах;
- он дошел до хорошего автомата;
- после этого почти всегда использовал его.

Но в другом seed он мог бы застрять на посредственном автомате.

## Что такое run

`run` - один независимый запуск эксперимента.

Для bandit это обычно значит:

- новый seed;
- новая среда;
- новый агент;
- новый процесс обучения.

Если мы запускаем стратегию 100 раз, мы получаем 100 оценок результата.

## Зачем усреднять

Когда мы считаем средний результат по многим runs, случайные удачи и неудачи частично компенсируются.

Например:

```text
epsilon = 0.0:
run 1:  673
run 2: -120
run 3:  210
...

epsilon = 0.1:
run 1:  555
run 2:  480
run 3:  530
...
```

Один run может выглядеть эффектно, но среднее по многим запускам честнее.

## Mean и standard deviation

### Mean

`mean` - среднее значение.

```text
mean = sum(values) / len(values)
```

Например, средний `total_reward` по 50 запускам.

### Standard deviation

`std`, или standard deviation, показывает разброс.

Если `std` маленький, стратегия ведет себя стабильно.

Если `std` большой, стратегия может иногда работать хорошо, а иногда проваливаться.

Для учебного проекта достаточно понимать интуитивно:

```text
mean высокий, std низкий  -> хорошо и стабильно
mean высокий, std высокий -> может быть хорошо, но нестабильно
mean низкий               -> обычно плохо
```

## Что будем сравнивать

Для каждого `epsilon` запустим несколько независимых runs.

Например:

```python
epsilons = [0.0, 0.01, 0.1, 0.3, 1.0]
runs = 50
```

Для каждого `epsilon` посчитаем:

- средний `total_reward`;
- std для `total_reward`;
- средний `average_reward`;
- средний `best_action_rate`.

## Главная идея

В RL нельзя слишком доверять одному красивому запуску.

Хорошая привычка:

```text
сначала посмотреть один run, чтобы понять механику
потом проверить много runs, чтобы понять надежность
```

Так мы сохраняем и эффект "вау", и инженерную трезвость.
