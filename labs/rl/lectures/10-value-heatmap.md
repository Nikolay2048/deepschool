# Лекция 10. Value heatmap

После Q-learning у нас есть Q-table:

```python
Q(state, action)
```

Она отвечает на вопрос:

```text
насколько полезно сделать action в state?
```

Но иногда хочется смотреть не на отдельные actions, а на сами состояния.

## Value function

Value function отвечает на вопрос:

```text
насколько хорошее это состояние?
```

Для Q-learning можно получить value из Q-table:

```text
V(state) = max_a Q(state, action)
```

То есть ценность состояния - это ценность лучшего действия из этого состояния.

## Пример

Допустим:

```python
Q[(2, 2)] = {
    "up": 0.5,
    "down": 0.8,
    "left": 0.2,
    "right": 0.4,
}
```

Тогда:

```text
V((2, 2)) = 0.8
```

Потому что лучший action из `(2, 2)` сейчас имеет Q-value `0.8`.

## Что покажет heatmap

На value heatmap каждая клетка окрашена по своему `V(state)`.

Обычно после обучения видно:

- клетки ближе к цели имеют большую ценность;
- клетки далеко от цели имеют меньшую ценность;
- стены не имеют value;
- стрелки greedy policy ведут по направлению роста ценности.

## Почему value не равно расстоянию

Value зависит не только от расстояния до цели.

На него влияют:

- reward за цель;
- штраф за шаг;
- штраф за стену;
- `gamma`;
- качество обучения;
- exploration во время training.

Если увеличить штраф за шаг, дальние клетки станут менее ценными.

Если уменьшить `gamma`, агент начнет меньше ценить далекую цель.

## Главное

Policy arrows показывают:

```text
что агент будет делать?
```

Value heatmap показывает:

```text
какие состояния агент считает хорошими?
```

Вместе они помогают понять, что реально лежит внутри Q-table.
