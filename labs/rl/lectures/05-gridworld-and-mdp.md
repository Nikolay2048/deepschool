# Лекция 05. GridWorld и MDP

До сих пор мы работали с bandit-задачей.

В bandit не было состояния:

```text
action -> reward
```

Агент выбирал автомат и получал награду. На следующем шаге ситуация не менялась: автоматов столько же, их скрытые средние награды те же.

Теперь переходим к полноценной RL-задаче:

```text
state -> action -> reward -> next_state
```

## Что меняется после bandit

В GridWorld агент находится в клетке сетки.

Например:

```text
A . . .
. # . .
. . . G
```

Где:

- `A` - агент;
- `G` - цель;
- `#` - стена;
- `.` - обычная клетка.

Теперь действие зависит от состояния.

Если агент стоит слева от стены, действие `right` может быть плохим.

Если агент стоит слева от цели, действие `right` может быть хорошим.

То есть одно и то же действие может иметь разный смысл в разных состояниях.

## State

В GridWorld state - это позиция агента.

Например:

```python
state = (row, col)
```

Если агент стоит в левом верхнем углу:

```python
state = (0, 0)
```

Если он стоит в третьей строке и четвертом столбце:

```python
state = (2, 3)
```

Индексация начинается с нуля.

## Action

В первой версии будут четыре действия:

```python
UP = "up"
DOWN = "down"
LEFT = "left"
RIGHT = "right"
```

Действие меняет позицию агента.

Например:

```text
state = (2, 3)
action = "up"
next_state = (1, 3)
```

## Transition

Transition - это переход из одного состояния в другое после действия.

```text
state + action -> next_state
```

Например:

```text
(2, 3) + up -> (1, 3)
```

Но переход не всегда простой:

- если агент идет в стену, он остается на месте;
- если агент идет за границу поля, он остается на месте;
- если агент попадает в цель, эпизод заканчивается.

## Reward

Reward задает, что агент должен хотеть.

Для первой версии можно использовать простую схему:

```text
+1.0  за достижение цели
-0.01 за обычный шаг
-0.05 за удар в стену или границу
```

Зачем штраф за шаг?

Если штрафа нет, агенту может быть все равно, сколько ходить до цели.

Маленький отрицательный reward за каждый шаг говорит:

```text
дойди до цели быстрее
```

## Terminal state

Terminal state - состояние, где эпизод заканчивается.

В нашем GridWorld цель `G` будет terminal state.

Когда агент дошел до цели:

```python
done = True
```

После этого эпизод нужно сбросить через `reset()`.

## MDP

MDP - Markov Decision Process.

Это математическая модель задачи, где агент принимает решения во времени.

Минимально MDP состоит из:

- states;
- actions;
- transition dynamics;
- rewards;
- terminal states или horizon;
- discount factor `gamma`.

В GridWorld это выглядит так:

| MDP component | GridWorld example |
|---------------|-------------------|
| state | позиция агента `(row, col)` |
| action | `up`, `down`, `left`, `right` |
| transition | новая позиция после движения |
| reward | `+1` за цель, штраф за шаг |
| terminal state | клетка цели |

## Markov property

Markov property значит:

```text
будущее зависит от текущего состояния и действия, а не от всей истории
```

В GridWorld, если агент сейчас в `(2, 3)`, для следующего шага не важно, как он туда пришел.

Важно только:

```text
текущая позиция + выбранное действие
```

Это упрощение лежит в основе большинства классических RL-алгоритмов.

## Что нужно понять

- Bandit: нет состояния, только action и reward.
- GridWorld: есть state, action, reward и next_state.
- State в нашей первой среде - координаты агента.
- Transition описывает, куда агент попадет после действия.
- Terminal state завершает эпизод.
- MDP - формальная рамка для таких задач.
