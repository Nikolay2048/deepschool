# Лекция 07. Q-learning

Теперь у нас есть полноценная среда GridWorld:

```text
state -> action -> reward -> next_state
```

Следующий шаг - научить агента выбирать действия лучше случайной политики.

Для этого начнем с Q-learning.

## Что такое Q

`Q(state, action)` - оценка того, насколько полезно сделать `action` в `state`.

Пример:

```text
Q((0, 0), "right") = 0.42
Q((0, 0), "down")  = 0.31
Q((0, 0), "left")  = -0.10
Q((0, 0), "up")    = -0.10
```

Это значит: из состояния `(0, 0)` действие `right` сейчас кажется лучшим.

## Q-table

В маленьком GridWorld можно хранить все Q-values в таблице.

Идея:

```python
q_table[state][action] -> float
```

Например:

```python
q_table[(0, 0)]["right"]
```

В начале агент ничего не знает, поэтому все Q-values можно поставить в `0.0`.

## Как агент выбирает действие

Используем знакомую epsilon-greedy стратегию:

```text
с вероятностью epsilon выбрать случайное действие
иначе выбрать action с максимальным Q(state, action)
```

От bandit отличается только то, что теперь Q зависит не только от action, но и от state.

В bandit было:

```python
Q[action]
```

В GridWorld стало:

```python
Q[state][action]
```

## Главная формула Q-learning

После шага агент видел:

```text
state, action, reward, next_state, done
```

Он обновляет Q-value:

```text
old_q = Q(state, action)
next_best_q = max Q(next_state, next_action)

target = reward + gamma * next_best_q
new_q = old_q + alpha * (target - old_q)
```

Если эпизод закончился:

```text
target = reward
```

Потому что после terminal state будущих наград уже нет.

## Что такое alpha

`alpha` - learning rate.

Он говорит, насколько сильно новая информация меняет старую оценку.

Если `alpha` маленький, агент учится медленно.

Если `alpha` слишком большой, оценки могут дергаться.

## Что такое gamma

`gamma` - discount factor.

Он говорит, насколько важны будущие награды.

В GridWorld цель может быть через несколько шагов. Поэтому `gamma` должен быть достаточно высоким, например `0.95`.

Если `gamma = 0`, агент смотрит только на reward текущего шага. Тогда он плохо поймет, что шаг к цели полезен, если награда за цель будет позже.

## Почему это работает

Q-learning распространяет ценность цели назад по состояниям.

Сначала агент узнает:

```text
из клетки рядом с целью хорошо пойти в цель
```

Потом:

```text
из клетки за два шага до цели хорошо пойти туда, откуда можно прийти к цели
```

И так дальше.

В итоге в каждой клетке появляется действие, которое ведет к цели.

## Что мы хотим увидеть

После обучения можно вывести greedy policy:

```text
> > v v
v # v v
v # > v
> > > G
```

Стрелки показывают лучшее действие в каждой клетке.

Это первый по-настоящему интересный момент: агент сам выучивает маршрут по наградам.

## Что нужно понять

- `Q(state, action)` оценивает полезность действия в конкретном состоянии.
- Q-table хранит такие оценки для маленькой среды.
- Q-learning обновляет оценку через reward и лучший будущий Q.
- `alpha` управляет скоростью обучения.
- `gamma` управляет важностью будущего.
- Terminal state обрабатывается отдельно: там нет будущей награды.
