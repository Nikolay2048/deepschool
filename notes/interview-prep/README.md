# Подготовка к ML/LLM-собеседованиям

Это живая база знаний для подготовки на позиции ML Engineer, LLM Engineer и, частично, Research Engineer.

## Как пользоваться конспектами

Каждая тема изучается на трёх уровнях:

1. **Интуиция** — что происходит и зачем это нужно.
2. **Математика и реализация** — формулы, предположения, код и эксперименты.
3. **Собеседование** — точная формулировка ответа, уточняющие вопросы и типичные ловушки.

Перед собеседованием сначала повторяются блоки «Короткий ответ», затем вопросы для самопроверки. Подробные объяснения нужны для восстановления понимания, если короткий ответ перестал быть очевидным.

## Принципы ведения

- Формулы сопровождаются объяснением смысла каждого множителя.
- Утверждения отделяются от полезных, но не гарантированных интерпретаций.
- Для каждой темы фиксируются типичные ошибки кандидатов.
- Практические результаты проверяются кодом или численным экспериментом.
- Новые пробелы добавляются в карту подготовки, а не теряются в переписке.
