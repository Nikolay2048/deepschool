# MLP в Transformer: преобразование признаков токена

Практика: [06c-token-mlp.ipynb](../../Seminars/transformers/06c-token-mlp.ipynb).

## 1. Зачем ещё один компонент

Attention вычисляет, от каких позиций и с какими весами собрать информацию. Его выход — вектор признаков для каждой позиции, уже учитывающий доступный контекст.

MLP (multilayer perceptron), также называемый feed-forward network или FFN, обучается нелинейно преобразовывать этот вектор. Один и тот же MLP применяется к каждой позиции отдельно. Он не обращается к соседним токенам напрямую, но обрабатываемое представление уже может содержать информацию о них благодаря attention.

Не стоит буквально приписывать нейронам готовые роли вроде «детектор существительного»: смысл признаков формируется при обучении.

## 2. Устройство выбранного MLP

Наш вариант:

```python
nn.Sequential(
    nn.Linear(d_model, d_ff),
    nn.GELU(),
    nn.Linear(d_ff, d_model),
)
```

Sequential передаёт выход каждого модуля следующему. Два Linear содержат обучаемые веса и bias. GELU — фиксированная покоординатная нелинейная функция, собственных обучаемых параметров у неё нет.

d_model — ширина представления токена на входе и выходе блока.
d_ff — ширина скрытого слоя внутри MLP. Для учебной модели выбираем d_ff=4*d_model. Это выбор архитектуры, не математическое требование; количество голов внимания его не определяет.

## 3. Формы и веса

При d_model=4, d_ff=16:

| Этап | Форма активаций |
|---|---|
| Вход x | (B,T,4) |
| Первый Linear | (B,T,16) |
| GELU | (B,T,16) |
| Второй Linear | (B,T,4) |

Расширяются признаки, а не число токенов. Первый слой не дописывает нули и не копирует исходные координаты: каждый из 16 выходных нейронов вычисляет свою взвешенную сумму всех четырёх входных признаков плюс bias.

Второй слой создаёт четыре новые комбинации 16 промежуточных признаков. Это не операция, обратная первому слою, и не гарантия восстановления входа. Возвращаем размер 4, чтобы результат ветви можно было сложить с x через residual.

Формы параметров:

- Первый Linear: weight (16,4), bias (16,).
- Второй Linear: weight (4,16), bias (4,).

Количество параметров: 16*4+16+4*16+4=148. В общем случае: 2*d_model*d_ff+d_ff+d_model. B и T в эту формулу не входят.

## 4. Формула: привычная запись строками

Для одного токена x — строка длины D:

```text
z = x @ W₁.T + b₁
h = GELU(z)
output = h @ W₂.T + b₂
```

W₁ имеет форму (d_ff,D), W₂ — (D,d_ff): в PyTorch строки weight соответствуют выходным нейронам. Для входа (B,T,D) тот же Linear действует по последней оси, с общими весами для всех позиций.

Это отличается от gamma и beta LayerNorm: там покоординатное умножение, а Linear смешивает разные входные признаки с помощью матрицы.

## 5. Зачем GELU между слоями

Если убрать нелинейность, два Linear подряд можно заменить одним аффинным преобразованием. Само добавление второго линейного слоя не создаёт нелинейной зависимости выхода от входа.

GELU применяется к каждому числу отдельно. Точная формула:

```text
GELU(z) = z * Φ(z)
```

Φ(z) — функция распределения стандартного нормального распределения: число от 0 до 1. Вычисление детерминированное, случайная выборка не производится. Большие положительные значения проходят почти без изменения, большие отрицательные приближаются к нулю; умеренные отрицательные значения не обязательно обнуляются. GELU(0)=0.

Для этого урока не нужно выводить Φ или производную GELU. Главное — между матрицами появилась нелинейность. GELU не является единственным вариантом активации; другие архитектуры могут использовать ReLU или gated MLP, но сейчас их не добавляем.

## 6. Что значит «отдельно для каждого токена»

Если изменить x[0,2], выход именно этого MLP для x[0,0] не изменится. Он использует только x[0,0] и общие параметры MLP. Это не значит, что во всём Transformer токены независимы: за связи между ними отвечает attention.

Нет отдельного MLP для каждой позиции. Один набор из 148 параметров в нашем примере обслуживает все позиции всех последовательностей. При backward вклады разных позиций в градиенты общих параметров суммируются.

## 7. Обучение и сборка блока

Обе матрицы и оба bias обучаются через общий loss модели: backward вычисляет градиенты, optimizer.step обновляет параметры. Отдельный loss для MLP не обязателен.

В будущем pre-norm блоке:

```python
x = x + attention(norm_1(x))
x = x + mlp(norm_2(x))
```

Вторая строка использует уже обновлённый первой строкой x. LayerNorm регулирует масштаб входа ветви; MLP преобразует признаки; residual прибавляет результат к текущему представлению. Полную сборку сделаем в следующем уроке без переписывания attention по памяти.

## 8. Ответ для собеседования

> Position-wise FFN в Transformer — общая для всех позиций сеть, нелинейно преобразующая признаки каждого токена. В нашем варианте это Linear(D,d_ff), GELU и Linear(d_ff,D). Она сохраняет число токенов и возвращает ширину D для residual-сложения. Напрямую позиции она не смешивает, но получает контекстные представления после attention.
