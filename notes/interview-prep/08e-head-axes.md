# Оси голов: подготовка к векторизации

Практика: [notebook 05b](../../Seminars/transformers/05b-head-axes.ipynb).

## 1. Что объединяем

В прошлом уроке каждая голова вычисляла Q отдельным Linear(D,head_dim). Их матрицы можно объединить по выходным строкам в одну матрицу (D,D), когда H*head_dim=D. Результат общей проекции имеет форму (B,T,D): для каждой позиции выходные признаки всех голов стоят рядом.

Это не разделение исходного эмбеддинга между головами: сначала каждая выходная координата проекции может использовать все входные признаки X, и только затем группируем выходные координаты по головам. K и V организуются аналогично.

## 2. reshape: разделить ось признаков

Пусть B=1, T=3, D=4, H=2, head_dim=2. Используем числа вместо реальных Queries:

```text
Позиция 0: [0,1,2,3]
Позиция 1: [4,5,6,7]
Позиция 2: [8,9,10,11]
```

reshape(B,T,H,head_dim) разбивает последний вектор на группы: для позиции 0 голова 0 получает [0,1], голова 1 — [2,3]. Число элементов не меняется: 1*3*4 = 1*3*2*2 = 12. Параметры не обучаются, выполняется преобразование формы данных.

## 3. transpose: переставить две оси

```python
q_split = q_flat.reshape(B, T, H, head_dim)
q_heads = q_split.transpose(1, 2)
```

Получаем (B,H,T,head_dim). Теперь q_heads[0,0] — матрица первой головы для всех позиций: [[0,1],[4,5],[8,9]]. Матрица второй: [[2,3],[6,7],[10,11]].

Прямой reshape(B,H,T,head_dim) даст ту же форму, но другую группировку: первая голова ошибочно получит [[0,1],[2,3],[4,5]]. Проверять только shape недостаточно — нужны проверки значений и соответствия индексов.

## 4. Зачем такая форма в attention

Q/K формы (B,H,T,head_dim) позволяют вычислить scores:

```text
(B,H,T,head_dim) @ (B,H,head_dim,T) → (B,H,T,T)
```

Для каждой пары batch/head выполняется своё матричное умножение, последовательности и головы не смешиваются. Маска (T,T) распространяется на B/H; softmax по последней оси нормирует источники для каждой Query каждой головы.

После умножения на V выход снова (B,H,T,head_dim). Это та же математика, что у отдельных голов. Саму реализацию и перенос весов сделаем после освоения осей.

## 5. Обратная сборка

Чтобы получить признаки всех голов для одной позиции, нужно сначала вернуть порядок (B,T,H,head_dim), затем объединить последние две оси:

```python
combined = heads_output.transpose(1, 2).reshape(B, T, D)
```

Прямое объединение без обратной перестановки может перемешать позиции с головами, сохранив внешне правильную форму.

transpose обычно меняет представление через strides, не переставляя физически все числа в памяти. Получившийся тензор может быть non-contiguous. reshape при необходимости делает копию; view требует совместимых strides и иногда нуждается в предварительном contiguous(). Пока используем reshape, не предполагая, что он всегда обходится без копирования.

## 6. Что проверяем сегодня

Соответствие конкретных групп чисел головам и позициям, отличие правильной перестановки от ошибочного прямого reshape и восстановление исходного тензора. Это подготовка к векторизации, не новая обученная модель и не замер ускорения.
