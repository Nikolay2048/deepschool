# LayerNorm: нормализация представления каждого токена

Практика: [06b-layernorm.ipynb](../../Seminars/transformers/06b-layernorm.ipynb).

## 1. Где мы находимся

У нас уже есть causal multi-head attention и residual connection. Следующий компонент — LayerNorm. После него разберём MLP и соберём Transformer-блок.

Attention передаёт информацию между позициями. LayerNorm в нашем блоке решает другую задачу: преобразует численные значения внутри вектора каждой позиции. Он сам не смешивает токены и не ищет связи между словами.

## 2. Зачем это нужно

Векторы внутри сети — не только исходные embeddings: после attention и residual это уже новые представления. Их средние значения и разброс могут различаться и меняться при обучении. Это влияет на величину сигналов, поступающих в следующие преобразования.

LayerNorm вычитает среднее и делит на величину, связанную с разбросом. Следующий слой получает представление с контролируемыми средним и масштабом до обучаемого преобразования. Это помогает оптимизации, но не гарантирует сходимость: learning rate, инициализация и другие части модели всё ещё важны.

Не путай с нормированием вектора до длины 1. LayerNorm не делает сумму координат равной 1, как softmax, и не превращает их в вероятности. Отрицательные числа допустимы.

## 3. Один токен: считаем по шагам

Пусть его вектор x = [1, 3, 5]. Здесь D=3.

1. Среднее: mean = (1+3+5)/3 = 3.
2. Отклонения от среднего: centered = [-2, 0, 2].
3. Дисперсия: variance = (4+0+4)/3 = 8/3.
4. Делитель: sqrt(variance + eps).
5. Нормализованный вектор: примерно [-1.225, 0, 1.225].

В формулах ниже умножение и деление покоординатные:

```text
mean = sum(x_i) / D
variance = sum((x_i - mean)^2) / D
normalized_i = (x_i - mean) / sqrt(variance + eps)
y_i = gamma_i * normalized_i + beta_i
```

Дисперсию делим именно на D, не на D-1. eps — небольшая положительная константа; при одинаковых координатах дисперсия равна нулю, но деление остаётся определённым.

У normalized среднее примерно 0. Дисперсия равна variance/(variance+eps), поэтому не строго 1. Для постоянного вектора normalized состоит из нулей.

## 4. Какие оси участвуют

Для x.shape == (B,T,D) используем nn.LayerNorm(D). Каждый x[b,t,:] нормализуется отдельно по своим D признакам.

Пример (2,3,4): две последовательности, три токена в каждой, четыре признака на токен. Получаем шесть отдельных средних и шесть дисперсий. Выход сохраняет форму (2,3,4).

```python
mean = x.mean(dim=-1, keepdim=True)  # (B,T,1)
centered = x - mean                # (B,T,D)
variance = centered.square().mean(dim=-1, keepdim=True)
normalized = centered / torch.sqrt(variance + 1e-5)
```

dim=-1 означает последнюю ось: здесь признаки, а не последний токен. keepdim=True оставляет ось длины 1. При вычитании broadcasting использует среднее данного токена для всех его координат. Среднее соседнего токена сюда не попадает.

Нормализация по T — другая операция. В decoder-модели совместные статистики по всей последовательности могут передать информацию из будущих токенов. Мы выбираем нормализацию только по D.

## 5. Что обучается

У обычного nn.LayerNorm(D) есть два вектора параметров:

- weight, или gamma: форма (D,), начальные значения 1;
- bias, или beta: форма (D,), начальные значения 0.

Итого 2*D параметров. Они позволяют сети подобрать масштаб и сдвиг для каждой координаты после нормализации. Они общие для всех позиций и последовательностей, но mean и variance у каждого входного вектора свои.

Статистики вычисляются из текущего входа — optimizer их не обучает. Gamma и beta получают градиенты от общего loss и обновляются optimizer.step(), если переданы оптимизатору. Сам LayerNorm не отключает autograd.

После обучаемых gamma и beta выход уже не обязан иметь нулевое среднее и единичную дисперсию. С elementwise_affine=False этих параметров нет: это удобно для первого опыта.

## 6. Место в нашем блоке

Выбранный вариант называется pre-norm: нормализация находится перед attention или MLP внутри residual-ветви.

```python
x = x + attention(norm_1(x))
x = x + mlp(norm_2(x))
```

norm_1 и norm_2 — разные модули со своими параметрами. В первом сложении прямой путь содержит исходный x, а не norm_1(x). Формы всех слагаемых (B,T,D).

Сейчас достаточно понять первый вызов нормализации. Целый блок соберём отдельно из готовых частей.

## 7. Не путать с BatchNorm

Наш LayerNorm не использует другие элементы batch для статистик текущего токена. Он работает и при B=1. В train и eval статистики берутся из текущего входа; переключения на накопленные средние нет. Это не означает, что весь Transformer ведёт себя одинаково в train/eval: например, dropout отличается.

## 8. Ответ для собеседования

> В Transformer с входом (B,T,D) LayerNorm(D) нормализует признаки каждого токена независимо от других позиций и элементов batch. Он использует среднее и дисперсию текущего вектора, затем применяет обучаемые покоординатные масштаб и сдвиг. Форма сохраняется, параметров по умолчанию 2D. В pre-norm блоке нормализация стоит перед преобразованием внутри residual-ветви.

Ловушки: dim=-1 — ось, не элемент; нормализация — не softmax; статистики — не обучаемые параметры; после affine-преобразования среднее не обязано быть нулевым.

Справка по API: [официальная реализация PyTorch LayerNorm](https://github.com/pytorch/pytorch/blob/main/torch/nn/modules/normalization.py). Точные свойства API сверены с документацией; численные примеры проверяются в ноутбуке.
