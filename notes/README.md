## Подготовка к собеседованиям

Системные конспекты для подготовки на позиции ML Engineer, LLM Engineer и Research Engineer находятся в [`interview-prep/`](interview-prep/README.md).

Там хранятся:

- подробная теория и выводы формул;
- короткие формулировки ответов для собеседований;
- типичные ошибки и вопросы с подвохом;
- задачи для самопроверки;
- журнал изученных тем и обнаруженных пробелов.
