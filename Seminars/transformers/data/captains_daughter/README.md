Скачано 2026-09-26 скриптом ../../download_captains_daughter.py. Подробная provenance и хеши — source.json. Извлечены абзацы 14 глав, а не точная типографская копия книги: отдельные элементы вне p могут отсутствовать. Убраны HTML, меню, надстрочные маркеры сносок; нормализованы Unicode NFC и пробельные символы. Регистр сохранён.

captains_daughter.txt содержит 189134 символа, включая заголовки глав. Notebook использует text из chapters.json без заголовков. Там текст переводится в нижний регистр в памяти; исходник остаётся неизменным.

Разделение урока 09: I–X train, XI–XII validation, XIII–XIV test. Test пока не оценивается. Источник один, поэтому оценка не претендует на перенос на другие книги и жанры.
