## Как выполнять notebook

1. Сначала ответить на вопросы разминки без запуска кода.
2. Выполнять ячейки сверху вниз и заполнять все `TODO`.
3. После эксперимента записывать наблюдение своими словами.
4. В конце выполнить `Restart Kernel → Run All`.
5. Сохранить notebook вместе с выводами ячеек для проверки.

Завершённые и переиспользуемые реализации позднее переносятся из notebook в `.py`-модули и покрываются тестами.
